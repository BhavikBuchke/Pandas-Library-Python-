#### **🛠 How to Run These Projects**

To explore the projects and run the code locally, please follow these steps.

### **Prerequisites**
Python (version 3.7 or higher)

### **Installation**

```sh
# Clone the repository
git clone https://github.com/BhavikBuchke/Pandas-Library-Python.git
```
```
#Navigate to the project directory:
cd Pandas-Library-Python
```
```
#Set up a virtual environment (recommended):
python -m venv penv
source penv/bin/activate _# On Windows, use_ `penv\Scripts\activate`
```
```
#Install the necessary packages:
pip install pandas jupyterlab
```
```
#Launch Jupyter Lab to view the notebooks:
jupyter lab
```
